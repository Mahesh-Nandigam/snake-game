# 🐍 Neon Rogue-Snake

A fast-paced, retro-futuristic Neon Snake game built with HTML5 Canvas, modern CSS animations, and procedural sound effects.

[![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-success?style=for-the-badge&logo=vercel)](https://snake-game-ten-vert.vercel.app)

---

## 🎮 Play Live
👉 **[Play Neon Rogue-Snake Live on Vercel](https://snake-game-ten-vert.vercel.app)**

---

## 🛠️ Features
- **Neon Glow Aesthetics**: Cyberpunk/retro-synth inspired visual theme.
- **Dynamic Audio**: Procedural synthesized audio effects using Web Audio API (`audio.js`).
- **Responsive Controls**: Keyboard arrow / WASD controls with smooth 60fps canvas rendering.
- **Zero Latency**: Pure client-side static web application hosted on Vercel Edge.
